## 👨🏻‍💻 Sobre mim

Sou desenvolvedor de software com foco em **C#/.NET e desenvolvimento Full Stack**, interessado em construir aplicações modernas, eficientes e escaláveis.

Tenho conhecimentos em desenvolvimento Back-end com **C#, .NET e ASP.NET Core**, além de desenvolvimento Front-end utilizando **React, JavaScript, HTML e CSS**.

Gosto de explorar novas tecnologias, compreender desafios de software e desenvolver soluções que conectem tecnologia, funcionalidade e experiência do usuário.

Atualmente, direciono meus estudos para arquitetura de software, boas práticas de desenvolvimento e evolução do ecossistema .NET.
